# 贡献指南

Python 3.9+，标准库运行时，原生 Web。规则必须给出明确证据与决策边界。

```bash
python3 -m aegis --demo --db /tmp/aegis-contribution.sqlite3
python3 -m unittest discover -s tests -v
```

新增检查应说明它判断什么、输入是什么、可能漏检/误报什么，以及在缺失信息时为何复核或拒收。不能用人工勾选绕过明确权限冲突。

质量指标按行集合合并，避免重复计数。供应商提供的样本没有独立随机抽样证据，不推广成完整批次通过。

修改共享协议时同步 FORGE 实现和协议文档，保持身份、规格、数据、原包绑定及期限检查。规则变更更新 ruleset，并用合成输入验证。

Web 修改需检查文件上传、核验责任人、结论、报告下载、错误提示、键盘操作与窄屏布局。

不要提交真实数据、合同、密钥、数据库、个人信息或机器专用路径。报告示例不要回显敏感原始值。
