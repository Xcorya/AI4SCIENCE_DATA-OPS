# 安全边界

AEGIS 0.1.0 是受信任单机用户的本地参考应用，只监听 127.0.0.1。核验人是具名声明字段，不是经过身份认证的账户。

文件 HMAC 校验完整性，不证明许可真实、来源真实或核验人身份。共享密钥持有者可签名；生产环境需要角色分离的签名与权限。

PII 检测仅覆盖选定字段和邮箱模式，不用于声明数据“无隐私风险”。检查例子不回显原始值，但原交付仍保存在 SQLite，state API 返回它。

不要将服务代理到公网、提交真实合同/数据/密钥，或依赖公共演示密钥做实际验收。事件日志没有防管理员篡改保障，报告尚未支持撤销。

报告问题提供合成最小重现、涉及的规则与可观察影响。发布者应配置 GitHub private vulnerability reporting；本地交付未设置专用远程报告地址。
