## 发现并修复的问题

| 原问题与复现 | 修复 |
| --- | --- |
| source=null、observations=[null] 等导致整批异常退出 | 检查嵌套结构和 ID，坏记录隔离或复核 |
| 同张审计图片使用 200 个不同来源组，能够被重复计数并认证 | 同标签按内容 SHA-256 去重；重复直接拒绝 |
| 更换哈希大小写可以绕过跨切分重复检查 | SHA-256 统一大小写后比较 |
| claim_scope 拼写错误绕过整段视频覆盖门槛 | 仅接受已定义作用域；非法值进入复核 |
| 页面将重叠窗口重复计入覆盖，且覆盖失败后逐标签仍显示暂定 | 使用区间并集；逐标签同步复核；任务目标清空 |
| 安装后离开仓库目录就找不到配置 | wheel 打包默认配置，支持任意工作目录 |
| 代码语义改变后旧证书可能沿用 | 证书指纹绑定引擎版本，发布 0.1.1 |
| 行内代码链接出现未展开的控制字符 | 修复嵌套渲染顺序；站点检查加入残留 token 检测 |
| 照片形态标签隐含真实拍摄来源 | 改为摄影外观；真实采集留给来源标签与元数据验证 |

非法 JSON 数值、畸形 RL 参考和错误配置也加入了回归检查。CLI 给出可读错误，语法错误显示文件名与行号，不打印 Python traceback。

## 浏览器实测

切换图像/视频，选择只覆盖 12/120 秒的视频示例：相关标签均进入复核，export_to_training=false、target=null。提高质量门槛后样本进入复核；搜索 acquisition.tem 返回对应标签；完整标签说明页及包含行内代码的链接文字正确打开。

下载 syn-vid-002-demo.json 后，实际在浏览器下载目录中读取并解析该文件：样例 ID 正确、demo_only=true、训练导出关闭、目标为空。浏览器自动化的 download 事件通知超时，但文件保存及内容已通过文件核对，未把界面提示当作文件成功的唯一依据。

## 尚不能证明的能力

没有执行真实视觉模型推理、真实金标精确率评测、模型训练、GitHub 远程工作流或公网 Pages 部署。当前没有从原始图片/视频直接生成观测的适配器，也没有可用的训练集或生产调度系统。

因此不能声称达到 98%/99% 识别精度、专业推理正确或获得训练收益。接入真实媒体解析与视觉模型后，仍需按独立来源组做金标审计，测量逐类精确率、覆盖率、成本及下游收益。
