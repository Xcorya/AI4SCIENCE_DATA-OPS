DESIGN PRINCIPLE

先证据，再标签，最后进入训练。

把“猜得像”与“可验证”分开。

CANDIDATE

Bo3 扩展候选空间

同一媒体生成三组可替代标签假设，保留区域、文本和时间依据。候选覆盖优先，模型重复输出不增加独立证据票数。

VERIFY

按依赖组复核证据

视觉、OCR、结构解析与时间验证分别提出支持或反证。同源模型、同一 OCR 上游和相同提示派生结果归为同一组。

RELEASE

校准后选择性接收

逐标签校准阈值，检查层级、互斥、来源权利和泄漏。仅保留各自有证据的标签；细分类依据不足时进入人工复核。
