图像与视频数据增长策略

数据增长以“独立验收通过的有效训练任务数”为主指标。抓取条数、生成 token 数和奖励模型均分只反映过程量。标签准确率、任务可回答性、来源合法性和评测隔离分别验收，不能互相抵消。

1 来源分层

先接许可清晰、有稳定资产 ID 和可追溯元数据的来源，再扩展难源。公开可访问与允许重新分发是两个字段。代码的 MIT 许可不会覆盖收集来的论文图、视频、模型权重或外部数据集。

来源类别优点主要问题入库方式
作者或机构的开放数据集结构、许可较容易核对标签体系各异、长尾不足按版本导入，保存数据卡
开放论文与补充材料图表密集、学科上下文丰富每篇许可不同、复合图、多版本逐项许可登记，图注与像素分通道
仿真与程序渲染能掌握底层参数和真值渲染分布与真实媒体存在差距参数、随机种子、程序版本随资产存储
科研演示与实验视频有时序、可构造事件题编辑、快放、字幕诱导、缺控制条件来源许可、镜头和时间映射齐备后使用
研究社区上传资产新颖、覆盖领域广质量与权限不稳定先隔离，再审查

未知许可资产可以在有授权的内部环境登记元数据，但不进入公开资产包或训练导出。本参考实现采取更简单的保守策略：未知或未允许使用的资产直接隔离。

2 标注单元与重复控制

分配 source_group_id、asset_id、unit_id、assertion_id。原图、裁剪、增强、QA、视频帧和转录都是派生节点。用 SHA-256 识别精确重复，再用感知哈希或嵌入发现近重复；阈值用人工核验的重复对调整，不能把视觉相似的不同实验合并。

同论文正文与补充材料、预印本与正式版、同实验的多视频，以及同视频的片段属于同一切分组。跨网站转载也要按内容簇归并。先切分来源组，再生成 QA，避免一张图的描述在 train、数值问题在 test。

3 四个数据池

池内容可以做什么
Gold专家标注、双人一致或仲裁后可判定独立评测、校准、验证器参考；用途事先分配
Accepted完整门控与适用认证通过的断言受控导出、抽样审计
Review模型冲突、边界不清、稀有方法主动标注与补证据
Quarantine权利不明、资产损坏、来源异常修复来源或停止处理

provisional 属于暂定识别结果，不得因为导出量少而升级成 Accepted。Gold 不是全局可随意复用的统一池；tune、audit、test 的成员保持隔离。

4 初始选样配方

下面是冷启动预算配方，供实验起步，不代表已验证最优：

人工预算比例样本目的
35%模型或专家分歧、父子标签冲突找到当前决策边界
25%从自动接收总体随机抽样检测共同幻觉、无偏审计
20%稀有类别与新来源补覆盖与分布漂移
20%定向难负例解决重要混淆对

精确率认证使用单独、预先定义的随机审计样本；不能直接使用上述富集样本估计总体 precision。若采用分层采样，保存抽样概率并使用对应估计与置信方法。当前代码不实现加权调查估计。

难负例重点包括：SEM/TEM/合成纹理，NMR/FTIR/普通峰图，实验/科学动画，真实仪器/CAD 渲染，倾倒/镜头切换，气泡/沸腾/化学反应，流程图/折线图，球棍分子/普通三维节点网络。每对都保存正例、邻类、不可判例和判断依据。

5 从简单到困难

先做可靠的形态识别与 grounding，再做专业方法识别，最后生成受条件约束的推理问题。简单清晰样本用于学习基础视觉概念；困难样本用于提高边界能力。复杂度不作为唯一保留标准。

QA 生成分四步：

  1. 从已核准断言或原始数据提取事实表，锁定真值来源。
  2. 选择可验证任务模板，再让模型改写自然语言。
  3. 检查问题是否要求媒体中不存在的量，是否有多个合法答案。
  4. 用程序或独立专家验证答案；有歧义进入拒识或偏好任务池。

例如，只能看见热力图而没有精确色标时，可以问“哪个区域更高”，不应凭像素颜色生成“精确温度是多少”。视频只看见加液，不应生成可验证的反应机理题。可以把额外实验条件写入题干，但必须明确它们是给定条件，不能声称来自画面。

6 RL 任务增长

先扩充验证器覆盖，再扩大任务量。新任务模板必须配真值、合法输出集合、错误答案与对抗样本。标签、区域和事件区间任务有明确的参考表示；开放科学解释更适合专家偏好或过程复核，不能直接冒充确定性 RLVR。

建议维护任务注册表：task_type, input_contract, reference_contract, reward_version, tolerance, eligibility, failure_modes。格式分必须被正确性硬门控；答案正确但证据错误，不给满分。不得把模型输出中的自评分写回 reward。

同一图扩写十道近似题并不创造十份独立信息。给每个来源组、模板和语义簇设置采样上限，报告唯一媒体数、唯一来源组数与任务多样性。训练中保留按领域、任务和难度的配额；用真实错误修订配比。

7 每轮闭环

冻结数据版本 → 训练 → 独立评测 → 错误聚类 → 分配人工与采样预算 → 更新专家或规则 → 重做 tune/audit → 小流量验收 → 发布下一版。

每轮比较新增数据、同量随机数据、难负例数据、无新增数据四组，保持模型与训练预算一致。报告有效任务数、精确率与区间、接收率、人工成本、跨来源表现、下游提升与回归。若只提高了审题模板熟悉度，不能据此断言科学推理能力提高。

8 发布 manifest

每个版本至少保存以下内容：

  • 数据来源、来源许可证据、允许用途、撤回联系方式或流程。
  • 资产与派生哈希、来源组、切分、工具和模型版本。
  • 标签与证据版本、人工仲裁记录、自动策略与认证作用域。
  • SFT/RL 任务 ID、参考答案版本、验证器版本、抽检报告。
  • 已知缺口、新增与撤回条目、上轮训练的回归结果。

公开包默认发布代码、规范、合成示例和可公开的 manifest。原始媒体按逐项许可决定发布方式。可追溯的引用不能替代重新分发授权。
