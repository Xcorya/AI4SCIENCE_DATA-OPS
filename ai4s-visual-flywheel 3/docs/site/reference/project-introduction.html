AI4Science 视觉数据飞轮项目介绍

AI4Science Visual Flywheel 面向科学图像与视频，探索如何把分散的科研媒体组织为可信标签、问答和可验证的模型训练任务。它覆盖科学图表、显微图、实验照片、结构示意、分子与工程渲染，以及实验录像、仿真和科学动画。

项目把视觉表达、采集方式、专业学科、视频形式、时序事件和任务适用性分别标注，避免把“看起来相似”直接当成专业结论。每条标签关联具体区域或时间区间；细标签需要自己的方法证据；多面板和混合视频保留多个局部标签。无法判断的内容进入未知或复核池。

算法采用高召回路由和 Best-of-3 候选，再以局部复看、专用解析、反证搜索及时间约束进行筛选。相同模型、相同 OCR 或共同上游的重复意见按依赖族去重。三次生成只是候选搜索，不能自动保证标签正确。

自动接收门槛由独立人工标注集验收：先在 tune 集确定阈值，再在 audit 集计算精确率置信下界。策略、本体、模型管线或来源分布变化时重新验收。通过筛选的断言可构成监督数据；拥有独立参考与可执行验证器的任务才进入相应 RL 候选池。奖励依据最终答案和定位证据，不依据模型自信或解释长度。

飞轮增长由错误驱动：模型分歧用于发现边界，随机审计用于发现共同错误，难负例用于修正专业混淆，新来源用于测试分布变化。训练后的收益仍由隔离测试和外部来源检验。

当前版本交付标签本体、算法说明、数据策略、标注与评测规范、Python 策略原型、合成示例和交互页面。它是可复现的研究起点；真实识别精度、生产成本和模型收益需要在接入媒体与模型后测量。
