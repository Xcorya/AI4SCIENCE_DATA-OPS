# HELIX 实跑复验报告

日期：2026-11-23。验证方式：独立空数据库、真实网络请求、真实远程文件、浏览器操作、HTTP 下载及自动检查。没有调用真实大模型，也没有执行模型训练。

## 结论

**可以作为可运行的数据加工与飞轮演示原型；目前不能完成“自动收集任意科学多模态资料 → 理解内容 → 生成科研级推理任务 → RL 训练 → 持续提升模型”的完整产线。**

演示构造和真实来源接入分别可运行，但两者之间仍缺少完整的多模态语义解析、科研任务生成与专用验证器。模型调用还需要配置实际服务，训练还需要单独搭建并验证环境。

## 发现并修复的问题

1. **空 XYZ 文件导致 IndexError。** 增加头部结构检查，现返回明确的输入错误。
2. **CSV/STL 缺少单位配置导致 KeyError。** 增加单位类型和非空检查；坏记录不会中止后续合法记录的导入。
3. **手工 facts 缺乏结构检查。** 增加对象、数值列表、有限数值、单位、数量名称及布尔标志校验，错误输入在入库前被拒绝。
4. **合法 JSON 但非对象的证据可能触发属性异常。** 现进入证据未通过的审核状态，不中断数值构造批次。

通过真实 HTTP 导入 `facts: []` 时，系统返回一条结构错误、创建 0 条资产，连接正常结束。

## 尚不能据此证明的能力

### 真实论文自动转训练数据：未打通

本次新抓取的 arXiv、Crossref 记录没有结构化数值 facts，许可仍为 unknown。直接对它们执行当前模板管线，**新增任务为 0**。因此“能采集元数据”不能表述为“已自动生产真实科研训练数据”。

### 真正的多模态理解：尚未实现完整链路

默认 image/video/CAD 等演示记录是带模态标签的 JSON 标注。实现了统一归档和少量文件解析器，但没有完成 PDF 图文联合理解、视频时序理解、图像证据定位或 STEP 语义解析。

### 真实 AI 生成：本环境未验证

检查到 HELIX_MODEL、HELIX_MODEL_KEY、HELIX_MODEL_BASE_URL 均未配置。真实模型模式明确报 “Model is not configured”，页面模型选项禁用，没有用模板冒充真实模型输出。

### RL 模型训练：未运行

本环境存在 torch，但缺少 trl、datasets。项目只提供可选训练入口，本次没有安装整套训练环境、下载模型或执行训练。导出格式可解析、奖励函数可运行，不能等同于训练器已跑通，更不能声称模型能力提升。

### 科研级正确率与规模化能力：未测得

当前自动验证是均值、首尾差、比值和极差。尚无科研级专家抽检、真实模型收益、百万级吞吐或多轮训练消融结果。

## 可复现命令

```bash
cd helix
python3 -m unittest discover -s tests -v
python3 -m helix --data-dir /tmp/helix-independent-check seed
python3 -m helix --data-dir /tmp/helix-independent-check run --limit 200
python3 -m helix --data-dir /tmp/helix-independent-check export \
  --format rl --include-demo --output /tmp/helix-independent-check/train.rl.jsonl
python3 -m helix --data-dir /tmp/helix-independent-check discover \
  arxiv "scientific machine learning" --limit 2
python3 -m helix serve --port 8877
```

网络内容与可用性会变化。已有数据库运行时，幂等处理可能使新增条数减少。

## 使完整目标成立所需的下一次实验

优先限定一个学科和一种证据：许可明确的真实表格 → 真实模型候选 → 独立验证 → 非演示训练集 → 实际训练器小批次运行 → 固定测试集评测。证明这一条真实链路后，再拓展图片、视频、CAD 和更多学科。
