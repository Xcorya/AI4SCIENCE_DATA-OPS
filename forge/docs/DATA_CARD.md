# 合成数据卡

版本 0.1.0。所有示例由本地脚本生成，不包含外部采集、真实供应商、个人数据或真实采购行为。

| 数据 | 来源 | 用途 |
|---|---|---|
| 24 条摘要记录 | `forge/store.py::demo_records` 的编号模板 | 演示字段与质量检查 |
| 4 家供应商 | 手工设定的合成名称、价格、质量声明 | 演示采购过滤及 Pareto |
| 需求规格 | 24 条、预算 CNY 1200、14 天 | 固定流程测试 |
| clean / defects / rights-gap | 同一批合成记录的确定性变体 | 演示通过、拒收、复核 |
| 合成许可 | `fixtures/RIGHTS.md` | 演示许可范围及独立核验记录 |

`language` 的 zh/en 是演示标签。文本均为英文模板，不代表真实多语种语料质量，也不用于训练收益评估。

重建：

```bash
python3 scripts/generate_fixtures.py
```

JSON fixtures 是**未签名正文**。AEGIS 的演示启动用运行密钥重新签名，普通验收入口不能直接接受未签名正文。

缺陷变体分别修改重复唯一键、空文本和字段类型：3/24 = 12.5% 缺陷。许可缺失变体删除 evidence 并将供应商核验声明设为 false。

日期是固定的演示元数据，许可示例截止日为 2030-12-31。超过该日期时正常规则应拒绝过期许可；届时更新样本及测试预期。

软件与合成 fixtures 采用 MIT。真实数据许可独立于本项目代码许可，需要按实际证据核验。未报告模型收益、采购节省或真实验收成功率。
