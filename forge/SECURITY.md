# 安全边界

FORGE 0.1.0 是受信任单机用户的本地参考应用，只监听 127.0.0.1，不提供远程认证、RBAC、财务下单或生产审批。

演示密钥公开，不用于真实数据。私有密钥只在可信本地服务间共享；持有者可签名，不能提供给不可信供应商。实际部署需身份认证、分离签发角色与非对称密钥。

原始交付与许可证据元数据保存在 SQLite，并会被本地 state API 读取。不要将服务代理到公网，或在公共 issue 中上传工作区数据库。

Host、Origin、JSON 内容类型、CSP 和体积检查减少浏览器误用，无法抵御恶意本机程序、受控浏览器、密钥泄露或数据库管理员篡改。

报告问题时提供合成最小重现、涉及的规则与可观察影响。未配置远程仓库前不存在项目专用私密报告地址；发布者应设置 GitHub private vulnerability reporting。
